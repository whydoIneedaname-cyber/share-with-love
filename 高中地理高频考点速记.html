01地理位置与地形特征描述
1. 地理位置描述 ▶

模板答题四要素

  • 半球位置：东/西半球，南/北半球
  • 纬度位置：低/中/高纬；热/温/寒带
  • 海陆位置：某大洋某岸、某大陆某部
  • 相对位置：位于XX方位，临/接/靠XX地区

口诀地理位置评价六维度

经纬度（→气候→农业种类/熟制）｜海陆（→降水/海运/海洋资源）｜相邻（→商贸/国际协作）｜交通（→运费/腹地）｜经济（→引资/技术）｜政治（→行政中心）
2. 地形特征描述 ▶

模板四句话

  • 地形类型多样/单一，以XX、XX为主
  • 地势起伏大/小，地势XX高XX低
  • 主要地形类型的分布
  • 特殊地貌（海岸线曲折、喀斯特、沙漠、冰川、火山等——有必写）

引申地形对地理要素的影响

地形 → 气候 + 河流 + 土壤 + 农业 + 工业 + 交通 + 城市

4. 等值线"五读法" ▶

口诀五步秒杀选择题

  • 读图名——明确等值线类型
  • 读数值——注意"最大/最小"，特别注意闭合等值线

6. 地球公转季节判断 ▶
三夏一冬选冬，三冬一夏选夏，遇到春秋不选；或画万能图找点看移动方向
7. 航天发射基地区位 ▶

模板六要素

  • 气象：风速小、晴天多、透明度好
  • 地形地质：平坦开阔、结构稳定
  • 人口：人烟稀少，可建禁区
  • 纬度：越低越好——线速度大、省燃料
  • 交通+国防
  • 夜间发射利于跟踪观测
03气候要素分析
8. 影响气温的因素 ▶
气温 = 纬度 + 海陆 + 地形 + 洋流 + 人类活动
  • 纬度高→气温低；纬度低→气温高
  • 夏季陆>海，冬季陆<海
  • 海拔高→气温低；迎风坡<背风坡
  • 同纬度暖流>寒流
  • 局部异常（等温线弯曲）→多为城市热岛
9. 昼夜温差 ▶

核心下垫面比热容

  • 比热容大→升温降温慢→温差小
  • 比热容小→升温降温快→温差大

标准论述两大模板区域

①西北地区：深居内陆→温带大陆性气候→光照强、昼夜温差大→利于糖分积累
②青藏高原：海拔高→空气稀薄→白天削弱作用小（辐射强）、夜晚大气逆辐射弱（保温差）→温差大
10. 影响太阳辐射的因素 ▶
太阳辐射 = 纬度 + 地形 + 光照（天气）
  • 纬度低→辐射强
  • 地势高、空气稀薄→削弱少
  • 晴天多→日照时间长
11. 影响降水的因素 ▶
降水 = 大气环流 + 地形 + 下垫面 + 海陆位置 + 洋流 + 人类活动
  • 大气环流：单一气压带/风带，或气压带风带交替控制
  • 地形：迎风坡多雨、背风坡少雨；海拔影响对流（如东非高原）
  • 下垫面：植被/湿地增湿；冷空气遇水→降雪（日本西北、五大湖）
  • 海陆：近海多、远海少（大区域）；局部看等降水量线
  • 洋流：暖流增温增湿，寒流降温减湿
  • 人类：人工降雨、城市雨岛
12. 气候特征描述 ▶
气候特征 = 气温特征 + 降水特征（+水热组合）
  • 气温：年均温高低 + 年较差 + 日较差
  • 降水：年降水量 + 年际分配 + 季节分配

成因两模式

  • 地带性：太阳辐射 + 大气环流
  • 非地带性：地形 + 洋流（记三种特殊气候分布）
13. 风向题四步 ▶
  1. 读数值→作垂线→伸手判断
  2. 看纬线→画"七压六风"
  3. 定位东亚/南亚→判断季节→季风风向
  4. 有锋面→看符号凸向→画箭头
04天气系统与气象灾害
14. 全球气候变暖 ▶

原因

  • 自然：太阳活动异常
  • 人为：①燃烧矿物燃料→CO₂增多；②毁林→吸收CO₂减少

影响

  • 海平面上升→淹没沿海低地
  • 极端天气增多（旱涝、暴雨）
  • 农业经济结构变化
  • 物种灭绝、生态系统改变

措施

减排（少用化石燃料/提能效/用新能源/控甲烷）
增汇（植树造林/保护原始林/固碳技术）
适应（培育良种/调农业结构/建海堤）
国际合作
15. 主要气象灾害对比 ▶
灾害成因防御
台风热带气旋强烈发展监测预报；沿海防护林
暴雨洪涝连续/短时大暴雨修堤坝/水库/分洪区；植树；预警系统
干旱长时期无降水/异常偏少水利建设；农林牧结合；耐旱作物
寒潮强冷空气入侵剧烈降温预报预警；提前防寒
滑坡岩体/土体沿滑动面下滑护坡工程；避开破碎地带
泥石流山区含泥沙石块特殊洪流植树造林；避让沟谷
注意灾情大小还与人口密度、经济发展程度正相关
16. 我国常见气象问题秒杀 ▶
  • 长江中下游伏旱（7-8月）：副高控制→酷热少雨
  • 华北春旱（3-5月）：①气温回升快蒸发旺 ②雨带未到 ③春播用水大
  • 台风/飓风/风暴潮：夏秋季节，热带洋面

洪涝成因三角度

①来水大：降水多/变率大、流域广/支流多、植被少
②排水不畅：地势低、河道弯、河道淤、占河道
③调蓄差：围湖造田、泥沙淤积
17. 防灾措施分类 ▶
  • 非工程：宣传教育、法规体系、监测预报、应急机制
  • 工程：防洪堤、防护林、护坡工程等
05海洋水体
18. 海水温度"四高四低" ▶
四高：低纬高、夏季高、暖流高、表层高
四低：高纬低、冬季低、寒流低、深层低
19. 海水盐度"四看法" ▶
盐度 = 看纬度（蒸发vs降水）+ 看海拔（结冰/融冰）+ 看洋流（暖高寒低）+ 看河流（淡水稀释）
20. 渔场区位"四地一指向" ▶
温带海区 + 浅海大陆架 + 洋流（寒暖流交汇/上升流）+ 河口处
共同指向：饵料丰富、营养盐类多
21. 盐场区位 ▶
盐场 = 含盐量/水质 + 地形（平坦广阔海滩）+ 天气（晴天多、蒸发旺、雨天少）
22. 洋流判读 ▶
  • 分布看纬度，东西岸性质相反
  • 洋流与等温线：凸向即流向
  • 题眼：影响气温、降水、盐度、渔场、定南北半球、定季节、顺水/逆水
06河流与水循环
23. 河流水系特征 ▶
水系特征 = 性质（内/外流）+ 流向 + 流程长短 + 支流多少 + 流域面积 + 水系形状
24. 河流水文特征 ▶
水文特征 = 径流量 + 年际/季节变化 + 补给类型与汛期 + 流速 + 含沙量 + 结冰期 + 凌汛 + 水能 + 航运价值
推导链经纬度→气候→气温/降水→结冰期/径流量；海陆轮廓/地形→流速/水能；植被→含沙量
25. 河流上中下游规律 ▶
  • 上游：起伏大、落差大、流速快、含沙量大、水能富、以侵蚀为主
  • 下游：起伏小、流速慢、含沙量小、航运大、以沉积为主

沉积地貌三位置

出山口→冲积扇｜中下游→河漫滩平原｜入海口→三角洲
三角洲成因 = 侵蚀 + 沉积 + 海水顶托
26. 河流开发与治理 ▶

开发

水能 + 农业（林/牧/渔/种植）+ 工矿业 + 航运 + 旅游

治理

上游 + 中游 + 下游（分段施策）
27. 水循环"三个箭头" ▶

环节

降水↓、蒸发↑、径流→；海陆间循环四环节：蒸发+水汽输送+降水+径流

人类活动影响四角度

  • 时间尺度：修水库、植树造林→改季节/年际分配
  • 空间尺度：跨流域调水→改空间分布
  • 生态角度：排干沼泽、超采地下水、破坏植被→负面
  • 水资源角度：超循环周期→枯竭；污水→水质型缺水

水循环意义

维持水量平衡 + 更新陆地淡水 + 物质迁移能量交换 + 影响气候生态 + 塑造地表形态

08自然带与地域分异
31. 地理环境整体性 ▶
一基础（地貌/气候）、两功能（生产/平衡）、两表现（统一演化、牵一发而动全身）

答题四角度

  • 要素与整体协调一致
  • 一要素变→其他要素甚至整个环境变
  • 区域间相互联系
  • 人类活动→"牵一发而动全身"

34. 垂直带谱判读 ▶
  • 南北半球：南坡同类自然带高于北坡→北半球
  • 热量带：山麓基带=当地水平自然带
  • 纬度高低：带谱越多→纬度越低
  • 迎风坡：降水多→自然带多、雪线低
35. 雪线影响因素 ▶
一看气温（正相关——气温高雪线高）；二看降水（反相关——降水多雪线低）
09人口与城市
36. 人口增长模式"四看法" ▶
看经济发展模式 + 看数字 + 看形状（人口金字塔）+ 看生产力发展水平
37. 人口增长率与迁移 ▶
人口增长率 = 自然增长率 + 机械增长率
人数极值由正转负时人口最多；由负转正时人口最少

人口迁移影响

  • 迁入地：利——廉价劳动力、促流通、促三产；弊——公共设施负担、管理难度、生态压力
  • 迁出地：利——加强对外联系、缓解人地矛盾、开发土地资源；弊——人才外流、劳动力减少
38. 城市区位 ▶
城市区位 = 气候 + 地形 + 地质 + 水文 + 资源 + 经济 + 政治 + 宗教 + 科技 + 旅游

功能分区秒杀

看面积（住宅区最大）｜看有钱（商业区付租最高）｜看隔离带｜看"高大上"（高级住宅区）
39. 城市化 ▶

三大标志

城市人口增加 + 城市人口比重上升（最主要指标）+ 城市用地规模扩大

城市化三表现

  • 人口城市化：城市人口数量/比重上升
  • 地域城市化：用地规模扩大
  • 产业城市化：二、三产业比重上升，一产下降
10农业
40. 农业区位大模板 ▶
大区位 = 光热水土地 + 劳市交政科 + X（特殊因素）

自然条件

  • 光照/热量/降水/雨热同期/昼夜温差
  • 土壤（肥沃、土层深厚）
  • 地形（排水好、适宜耕作）
  • 灌溉水源（河流/地下水/冰雪融水/绿洲）

社会经济条件

  • 劳动力（数量/价格/素质）
  • 市场（需求量/远近）
  • 交通（保鲜冷藏技术）
  • 政策/科技/机械/历史经验/饮食习惯
  • 地租/商品率
41. 农业小区位 ▶
小区位 = 地价 + 单产 + 需水量 + 交通 + 市场
优先考虑市场；主观大题要结合播种期+生长期+收获期
42. 作物品质优/农产品畅销 ▶

品质优良（如东北水稻、新疆瓜果）

  • 昼夜温差大→糖分积累多
  • 低温→病虫害少→农药少
  • 光热充足、光照时间长
  • 雨热同期
  • 土壤肥沃、土层深厚

农产品畅销

  • 品质好、市场需求大
  • 反季节销售（时间差）
  • 生态绿色无污染
  • 交通便利
  • 易保存、便于长途运输
43. 农业地域类型判断"三看" ▶
看生产对象 + 看生产目的 + 看生产规模
44. 农业可持续发展（分区域） ▶
区域措施
平原区增施有机肥；调整结构；多种经营；生态农业
林区退耕还林；综合开发利用
丘陵山区封山育林、保持水土；发展立体农业
牧区退耕还草；合理载畜量；人工草场；轮牧
灌溉农业区节水农业；合理灌溉防盐渍化；兴修水利
通用少用化肥农药；发展生态农业

主观题万能模板

调结构（农林牧副渔+二三产）→ 产业化（龙头企业/延长链/提附加值）→ 基建 → 推技术 → 改生态（高产/优质/高效/生态/安全）
11工业与产业转移
45. 工业区位模板 ▶
工业区位 = 原动水土地 + 劳市交政科 + X

自然条件

  • 地形/水源/资源能源/环境优美（高新产业）

社会经济条件

  • 市场/交通/信息通达度/科技/劳动力/政策/地租/军事国防/工业惯性/产业协作/工业基础
46. 工业集聚与分散 ▶

集聚

共用基础设施降成本 + 信息交流协作 + 规模效益（弊：加剧污染）

分散

  • 充分利用各地区位优势（发达国：资金/技术/人才；发展中国家：廉价劳力/资源/低地租）
  • 扩大影响力，实现全球战略
  • 减少本地区污染（污染产业向外转移）
传导原则利益最大化、成本最小化
47. 产业转移 ▶

原因

劳动力 + 地价 + 内部交易成本 + 其他（市场/政策/环境）

对迁入地

  • 利：资源开发→经济发展→就业；促城市化/基建；促产业结构升级/三产
  • 弊：环境污染/生态破坏；资源消耗增加；占用耕地

对迁出地

  • 利：减少资源消耗、减轻污染；促产业升级；腾出空间发展高端产业
  • 弊：短期经济衰退、失业增加
12交通与工程区位
48. 交通线修建的影响 ▶

有利

  • 完善交通网、缩短时空距离、缓解运输压力
  • 促经济发展、资源开发
  • 加强对外交流联系
  • 边疆地区：促民族团结、国家安全
  • 带动区域发展（振兴/开发/崛起）

不利

  • 破坏生态环境
  • 不合理施工诱发地质灾害
  • 破坏传统文化独立性
49. 修交通线的自然限制因素 ▶
  • 地形崎岖、地势起伏大（云贵/青藏/山区）
  • 地质差：断层、喀斯特广布
  • 河网密集（南方）
  • 生态脆弱（青藏/云贵/西北/黄土高原）
  • 多风沙、荒漠化（西北）
  • 多灾害：南方湿热/台风/海水侵蚀；北方极寒/寒潮/冻土；青藏地震/缺氧/冻土
社会经济决定因素经济落后→需求小；资金/技术/劳动力不足
50. 港口/机场/高铁站选址 ▶

港口（7要素）

港阔水深不冻不淤 + 背风浪小 + 地形平坦地质好 + 海岸线曲折多港湾 + 经济腹地广（决定因素）+ 基建完善 + 多式联运便利

机场（6要素）

平坦开阔排水好 + 地质好 + 晴天多雨雾少逆风 + 距市区远 + 交通便利 + 经济发达需求大

高铁站/长途站（4要素）

地形平坦地质好 + 市区郊区（地租低/面积大/避拥堵/促郊区）+ 交通便利 + 经济发达需求大
51. 核电站选址 ▶
远离城市安全 + 地形平坦地质好无断层 + 临海/河便于冷却水 + 交通便利近港口铁路
52. 修水利工程的影响 ▶

有利

  • 调节径流、缓解下游水旱
  • 减下游泥沙淤积、缓解地上河
  • 发电/航运/养殖/旅游
  • 调节气候、增降水减温差

不利

  • 诱发地质灾害（地震/滑坡/泥石流）
  • 淹没上游耕地、移民
  • 生物多样性减少
  • 入海沙量减→三角洲退化、海岸侵蚀
  • 地下水位上升→土地盐碱化
13资源开发与跨区域调配
53. 资源/能源短缺措施 ▶
①加大勘探增产量 ②跨区域调配（南水北调/西气东输/西电东送/北煤南运）
③优化能源结构、开发新能源 ④增加进口、建储备
⑤提技术、提利用率 ⑥提节约意识、减浪费
54. 资源跨区域调配分析思路 ▶
原因（分布差异+供求差异）→ 线路选择（沿线自然/人口/城市/经济）→ 意义（调入区+调出区的社会/经济/生态效益）

以西气东输为例

对东部（调入）对西部（调出）
缓解能源短缺；带动相关产业；改善能源结构/大气环境；减轻铁路压力 资源优势→经济优势；推基建、增就业；促天然气综合利用；改善大气、提高生活质量
55. 资源开发条件评价 ▶
基础好：储量大、分布广、质量好、厚度大、埋藏浅
拉动强：距市场近、市场广阔
有保证：交通便利
56. 发达地区 vs 落后地区优势 ▶

发达地区

资金足、劳力素质高、科技强、管理好、法制完善、市场广、交通便、物流发达、信息通达、环境优、政策支持、基建好、协作强

落后地区

劳力丰富廉价、能源资源富、市场广、地租低、政策支持、发展潜力大

14可持续发展与环境问题
57. 环境问题三层表现 ▶
环境问题 = 资源短缺 + 环境污染 + 生态破坏

成因 = 自然原因 + 人为原因（重点）

措施六手段

宣传教育 + 法规体系 + 行政 + 经济 + 技术 + 生物措施
58. 生态环境问题判断 ▶
区域特征可能问题
远离海洋、降水稀少的内陆荒漠化
丘陵/季风区高原/降水集中植被稀疏水土流失
山地森林破坏、水土流失、生物多样性减少
平原耕作区水土流失、湿地减少

  4. 完善交通网
  5. 加强培训，提劳动力素质
  6. 产业结构升级、促三产（绿色旅游/观光农业）

  10. 提产品品质、扩营销、树品牌
