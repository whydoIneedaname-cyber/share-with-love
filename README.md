# 学习资料库

个人学习过程中整理的笔记、分析、PDF 与音频资料，免费开放，供学习交流使用。

## 内容说明

本仓库收录个人学习过程中产生的以下材料：

- **笔记**：学习过程中整理的笔记（Markdown 等文本格式）
- **分析**：对学习内容、习题、材料等所做的分析与总结
- **PDF**：整理成册或收集的 PDF 文档资料
- **音频**：学习相关的音频记录（如课程录音等）

## 使用方式

- 直接浏览仓库文件即可使用
- 如需下载，可 Clone 仓库或下载 ZIP

- 音频与 PDF 文件通常体积较大，若超过平台单文件大小限制，建议使用 Git LFS 或网盘链接
